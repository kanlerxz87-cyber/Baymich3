# Baymich3 — SF Bay Area Michelin Dashboard

A static dashboard of Michelin-listed restaurants in the San Francisco Bay Area (MICHELIN Guide California 2026), with analysis, open questions, and suggestions.

- **Live site (GitHub Pages):** https://kanlerxz87-cyber.github.io/Baymich3/
- **Data:** `data/restaurants.json` (starred and Bib Gourmand rows, each with a source URL), `data/analysis.json` (summary, questions, suggestions, repo review, data conflicts)
- **Build:** `python3 scripts/build_site.py` regenerates `docs/` (no dependencies)
- **Coordination:** see `COORDINATION.md` for task claims and the verification log

Blank or "Unverified" fields mean the value was not confirmed from an official source. Nothing is inferred.
