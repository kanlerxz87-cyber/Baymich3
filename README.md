# Bay Michelin

A mobile-friendly, source-first Michelin Bay Area dining and lodging planner prototype.

## Current evidence boundary

The populated restaurant table contains only the Bay Area entries explicitly described in Michelin's official **2025 California selection** release: Enclos (Sonoma, two stars) and Kiln (San Francisco, two stars). These are dated 2025 outcomes, not verified 2026 standings. The dataset is intentionally partial. No prices, hours, social accounts, hotel rates, rankings, or map coordinates are invented; absent values are labeled unverified and review questions are surfaced in the site.

Primary source: [Michelin Guide California 2025 selection (official)](https://www.michelin.com/en/publications/products-and-services/michelin-guide-california-2025-selection), published June 27, 2025.

## Run locally

Open `index.html` in a browser, or serve the repository with any static HTTP server. No build dependencies are required.

## GitHub Pages

A GitHub Actions workflow publishes the static site from the current Arena-managed branch. The repository must have Pages configured to use **GitHub Actions**; repository administrators may need to enable that setting. Deployment requires a successful workflow run and is not confirmed just by this source change.

## Verification and limitations

The source record and known gaps are documented in `COORDINATION.md` and on the site's Sources & flags section. Before making bookings, verify current Michelin status, venue menus/hours, hotel quotes for travel dates, and official social accounts directly with providers.
