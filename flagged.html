How this list is kept honest

Two failure modes are worth naming, because both looked like success:

  • A blank that was filled with a plausible value. Bardessono carried The French Laundry's street address for two sessions. It was plausible, in the same town, on the right street. It is now blank-checked against the hotel's own contact page.
  • The page and the data disagreeing. The starred table was hand-maintained, so a repaired CSV did not change what visitors saw. All ten pages are now generated from the data by tools/build_site.py, and the counts are recomputed on every build.

If a row cannot be sourced, it says so. That is the only way a table like this stays worth reading.
