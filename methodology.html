Method — how this site is built and verified

Sources (in order of trust)

1. MICHELIN Guide official pages — the 2026 California article (stars, 24 Jun 2026) and each restaurant's guide.michelin.com page (address, price level, hours, website).

2. Restaurant and hotel official sites — the restaurant's own pages (prices, hours, social icons, booking pages).

3. Booking partners named on the official site (OpenTable, Tock) — used for booking links, not for prices unless the restaurant states them.

4. Third-party sites (press, blogs, aggregators) — never used for a value in the table. They can be listed as leads only.

Rules

  • A blank cell is Unverified and must not be filled by inference.
  • Price for 2 = per-person price × 2 + service charge (formula shown). Tax, beverages, and gratuity are excluded unless the official page includes them.
  • Michelin's "$$$$" is a price level, not a dollar amount. It is shown separately.
  • Two official sources that disagree are both shown and flagged as a Conflict.
  • Each row carries a "checked" date and the verification log lists every URL used.

Geography

  • Core (9 counties): San Francisco, San Mateo, Santa Clara, Alameda, Contra Costa, Marin, Sonoma, Napa, Solano. This is the standard Bay Area definition used for the star count and hotel ranking.
  • Extension (not in the Core counts): Carmel-by-the-Sea (Monterey County) and Elk (Mendocino County).
  • Michelin's own "San Francisco and surroundings" list is a different geography and is shown only for comparison (see Flagged F9).

Hotel ranking

  • Metric: count of Core starred restaurants in the hotel's cluster.
  • Clusters: C1 SF (25), C2 Peninsula (5), C3 East Bay (2), C4 Marin (1), C5 Wine Country (8).
  • Hotels in the same cluster are tied. Distance-based ranking needs verified coordinates (not done).

Build

  • Data: data/restaurants.csv, data/hotels.csv.
  • Pages: restaurants.html and hotels.html are generated by scripts/build_tables.py. Edit the CSV, then run the script.
  • The site is plain HTML/CSS/JS. There is no framework and no external tracking.
